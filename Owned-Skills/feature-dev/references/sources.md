# 공개 참고와 작성 범위.

이 패키지는 코드 조사·범위·설계·최소 구현·검증을 연결하도록 직접 작성했으며 저장소의 MIT License를 따른다. 타사 명령 본문·에이전트 템플릿을 포함하지 않는다.

- [Anthropic 공식 플러그인 저장소](https://github.com/anthropics/claude-plugins-official)는 기능 개발 명령의 공개 배포 경로다. 별도 플러그인을 사용할 때만 해당 원본의 설치·라이선스·도구 요구를 확인한다.
- [Agent Skills 패키지 표준](https://agentskills.io/specification)은 스킬과 참조 리소스의 구조를 확인하는 공식 자료다.

이 자체 절차는 고정 하위 에이전트·모델·호스트 도구 없이 수행한다. 전문 스킬이 없을 때도 본문의 조사·실패 재현·최소 수정·실제 검증·리뷰 단계를 직접 따른다.
