# 공개 참고와 작성 범위.

이 패키지는 코드의 신뢰 경계·입력 제어·위험 사용처·영향을 연결해 검토하도록 직접 작성했으며 저장소의 MIT License를 따른다. 타사 스킬·구현 예제·라이선스 사본은 포함하지 않는다.

- [Addy Osmani의 보안 스킬](https://github.com/addyosmani/agent-skills/blob/aeac41d4d005999432bb7312f7ff06383a91d59d/skills/security-and-hardening/SKILL.md)은 경계·경로·의존성 도달성을 살피는 공개 참고 자료다.
- [OWASP Top 10](https://owasp.org/www-project-top-ten/)은 웹 공격 유형의 공식 참고다. 목록 이름만으로 해당 코드에 취약점이 있다고 단정하지 않는다.

검토는 허용된 읽기와 안전한 로컬 재현을 기본으로 하며 운영계 공격·비밀 노출·강제 업데이트로 확대하지 않는다. 현재 버전·실행 경로와 공식 공지를 확인할 수 없는 부분은 검토 공백으로 남긴다.
