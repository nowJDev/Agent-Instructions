# 공개 참고와 작성 범위.

이 패키지의 실행 절차는 Agent-Instructions에서 직접 작성했으며 저장소의 MIT License를 따른다. 타사 스킬 본문·참조 파일·라이선스 사본은 포함하지 않는다.

- [Anthropic 공식 Claude API 스킬](https://github.com/anthropics/skills/tree/dbd4588f9e1033efb41dad4bef2f7947c8993d44/skills/claude-api)은 언어별 API·오류·도구 호출 자료의 공개 탐색 경로다. 필요한 원문은 사용 시 공식 출처에서 확인한다.
- [공식 SDK 안내](https://docs.claude.com/en/api/client-sdks)와 각 SDK의 설치 버전·타입·예제를 기준으로 한다.
- 최신 모델·가격·한도는 본문이 연결하는 공식 페이지에서 조회하고 날짜와 적용 버전을 기록한다. 이 문서에는 고정 모델 ID·가격을 캐시하지 않는다.

외부 문서를 읽을 수 없으면 설치 버전으로 확인 가능한 범위만 답하고 최신 정보·인증·원격 응답의 미검증을 명시한다.
