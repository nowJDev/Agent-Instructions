# 공개 참고와 작성 범위.

이 패키지는 변경 범위·호출자·재현 조건·검증 결과를 근거로 검토하도록 직접 작성했으며 저장소의 MIT License를 따른다. 타사 스킬 실물·라이선스 사본·개인 프로젝트 참조는 포함하지 않는다.

- [Addy Osmani의 코드 리뷰 스킬](https://github.com/addyosmani/agent-skills/blob/aeac41d4d005999432bb7312f7ff06383a91d59d/skills/code-review-and-quality/SKILL.md)은 여러 품질 관점과 검증 근거를 살피는 공개 참고 자료다.
- [Git diff 공식 문서](https://git-scm.com/docs/git-diff)는 staged·unstaged·기준 리비전의 차이를 확인할 때 사용한다.

검토 순서와 권한 경계는 본문 자체에 완결돼 있다. 외부 예제의 자동 mutation·일괄 구조 기준·별도 모델 강제를 수행하지 않는다. 원격 게시·코드 수정은 사용자의 실제 요청 범위로만 판별한다.
