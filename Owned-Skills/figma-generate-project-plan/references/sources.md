# 공개 참고와 작성 범위.

이 패키지는 PRD를 섹션별 계획 초안과 검증 가능한 보드 작업으로 연결하는 자체 절차이며 저장소의 MIT License를 따른다. 타사 워크플로·레이아웃 원문과 개인 플러그인 경로는 포함하지 않는다.

- [Figma Plugin API 공식 문서](https://developers.figma.com/docs/plugins/)에서 실제 노드·페이지·폰트·편집기 지원을 확인한다.
- [Figma MCP 공식 안내](https://developers.figma.com/docs/figma-mcp-server/)에서 현재 연결의 도구·인증·지원 범위를 확인한다.

공식 API 문서만 읽었다는 이유로 필수 호스트 스킬이나 연결 도구를 대신하지 않는다. 필요한 스킬·도구가 없으면 섹션별 표·메모·Mermaid 초안만 제공한다. 노드 수정은 현재 호출이 만든 ID 또는 사용자가 수정하도록 지정한 ID로 한정하며 소유권·부분실패 상태가 불명확하면 멈춘다.
