# PR 종합 리뷰.

리뷰 요청은 수정·커밋·외부 게시 권한이 아니다.

## 독립 실행의 공통 검토.

설치된 code-review가 있으면 전체 절차를 읽고 적용한다. 없어도 다음 공통 검토를 직접 수행한다.

1. 읽기 전용 진단이 기본이다. 적용 지침·요구사항·검증 명령을 확인하고 staged·unstaged·untracked 변경을 구분한다. Git 변경이 없어도 명시된 파일·증상은 현재 코드 진단으로 검토한다.
2. 변경 파일을 처음부터 끝까지 읽고 가용 검색 도구로 호출자·인터페이스·export·설정·fixture·테스트와 데이터 흐름을 추적한다.
3. PR은 base/head SHA를 확정하고 대상 SHA의 전체 본문을 읽는다. 워킹트리와 원격 PR의 다른 버전을 섞지 않는다. 범위 불일치면 올바른 자료를 확보하기 전 그 부분의 결론을 보류한다.
4. 정상 입력·null/빈 값·실패·재시도·동시성·권한 경계에서 계약을 확인하고 재현 조건과 사용자 영향을 입증한다. 테스트 통과만으로 결함 부재를 단정하지 않는다.
5. 필요한 최소 검사는 기존 권한 안에서만 실행한다. 설치·네트워크·데이터 변경이 필요하면 실행 범위를 확인한다. 자료/도구/검사 실패는 미검증으로 남긴다.
6. 심각도, 파일·줄, 재현 조건, 실제 영향, 근거, 최소 수정안을 보고한다. 확정 결함·선택 제안·미확인 의심을 구분하고 같은 근본 원인의 중복을 합친다.
7. 실제 검사 명령·결과·검토 SHA·읽지 못한 범위와 남은 위험을 남긴다. 비밀값·인증 헤더·개인 데이터는 값 대신 위치와 유형만 보고한다.

## 입력과 도구 확인.

1. PR URL·번호 또는 로컬 변경, 요청된 관점과 병렬 실행 여부를 확인한다.
2. 지원 관점은 `code`, `tests`, `errors`, `comments`, `types`, `simplify`, `all`이다. 이름을 실제 내장 명령으로 가정하지 않는다.
3. GitHub 읽기 도구·Git·`rg`·전체 파일 읽기를 확인한다. 기준과 대상 SHA는 모든 검토에 동일하게 전달한다.
4. 먼저 공통 절차로 변경 파일과 연관 호출자·테스트 목록을 정한다. 접근 불가 파일은 별도로 표시한다.

## 관점을 선택하고 실행하기.

- `code`는 요구사항·동작·구조 경계를 확인한다.
- `tests`는 중요 정상·실패 경로를 실제 관찰하는지와 회귀 누락을 확인한다.
- `errors`는 예외 삼킴, 조용한 기본값, 잘못된 재시도와 자원 정리를 추적한다.
- `comments`는 주석·문서가 실제 동작과 일치하는지 확인한다.
- `types`는 불변식·null·경계 검증·공개 계약을 확인한다.
- `simplify`는 동작 보존을 전제로 제안만 수집한다. 리뷰 요청을 수정 권한으로 바꾸지 않는다.
- `all`이면 변경에 맞는 관점만 선택하고 생략 이유를 짧게 기록한다.
- 병렬 요청이 없으면 필요한 관점을 순차로 검토한다.
- 병렬 요청이 있고 서브에이전트 도구가 있으면 독립 관점을 분담한다. 각 작업에 대상 SHA·범위·읽기 전용·비밀 비노출 조건을 전달한다.
- 도구가 없으면 같은 관점을 순차 수행하고 실제 병렬 검토를 했다고 쓰지 않는다.

## 통합과 실패 처리.

1. 각 발견의 파일·줄·재현 조건을 원문에서 재확인한다.
2. 같은 근본 원인의 중복을 합치고 모순되는 발견은 근거를 비교한다.
3. 검토자가 실패하거나 자료가 없으면 그 관점을 미검증으로 남긴다.
4. 관련 검증 명령의 실제 결과를 확인하되 전체 검토를 테스트 통과로 대체하지 않는다.
5. 근거 없는 스타일 제안으로 필수 수정 목록을 늘리지 않는다.

## 증거 출력.

- 심각도, 관점, 파일·줄, 재현 조건, 사용자 영향과 최소 수정안을 함께 제시한다.
- 필수 수정, 선택 제안, 남은 검증을 구분한다.
- 검토 SHA와 실제 수행 관점·검사·미검토 범위를 적는다.
- PR 코멘트 게시, 메시지 전송, 파일 수정·커밋·병합은 자동 수행하지 않는다.

PR 조회 방법은 [GitHub CLI PR 안내](https://cli.github.com/manual/gh_pr)를 참고한다. 고정된 내장 명령이나 모델·에이전트 수를 전제하지 않는다.
