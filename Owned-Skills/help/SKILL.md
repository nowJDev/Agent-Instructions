# Ralph 도움말.

## 요청 해석.
- Ralph 문맥이면 이 스킬을 사용한다. 문맥 없는 `help`는 어떤 도구의 도움말인지 먼저 확인한다.
- 도움말 요청은 읽기 전용이다. 루프 시작·예약·상태 파일 생성·삭제를 실행하지 않는다.

## 설명 절차.
1. 현재 호스트와 설치 여부를 확인 가능한 범위에서 파악한다. 설치되지 않은 도구를 사용 가능하다고 말하지 않는다.
2. Ralph는 같은 목표를 반복하고 이전 파일·Git 변경과 검증 결과를 다음 시도에서 참고하는 방식이라고 설명한다.
3. Claude Code 플러그인은 Stop hook 재주입을 사용할 수 있지만, Codex에 동일 hook이 있다고 가정하지 않는다. Codex의 대체는 현재 세션에서 명시된 한계와 실제 검증을 갖춘 반복이다.
4. 설치돼 있으면 시작은 `ralph-loop`, 취소는 `cancel-ralph`, 일반 반복은 `loop` 스킬로 안내한다. 없으면 아래 핵심 절차를 설명하고 설치를 강제하지 않는다.
5. `--max-iterations`와 `--completion-promise`의 의미를 설명한다. 현재 설치 버전의 원본·도움말과 실제 지원 옵션을 확인한다.
6. 양의 유한 횟수와 검증 가능한 완료 조건을 함께 쓰는 예를 하나 제시한다. 종료 조건 없는 무한 반복을 권장하지 않는다.
7. 성공은 완료 문구가 아니라 테스트·관찰 증거로 판단하며 사용자 취소·한계 소진은 성공과 별개라고 설명한다.
8. 보조 스킬이 없으면 목표·양의 최대 횟수·완료 검사를 정하고 매 결과를 관찰해 종료하는 절차를 안내한다. 취소는 다음 반복 중단·소유 작업 취소·중단 상태 확인으로 설명한다. 설명 중 실행하지 않는다.

## 예.
“테스트 실패를 최대 3회 수정하고, 실제 테스트가 통과하면 완료로 보고해줘.”
이는 설명 예시이며 자동 실행 지시가 아니다.

## 결과.
핵심 원리, 현재 호스트의 지원 범위, 시작·종료·취소 방법과 주의할 한계를 짧게 정리한다.
버전·설치 상태를 확인할 수 없으면 그 불확실성을 그대로 남긴다.

## 출처.
이 문서는 유한 반복과 취소 경계를 설명하는 자체 작성 안내다. Claude 이벤트 구조는 [공식 hooks 문서](https://code.claude.com/docs/en/hooks)를 확인하고, 플러그인 옵션은 현재 설치 버전의 도움말과 대조한다.
