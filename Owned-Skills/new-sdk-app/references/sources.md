# 공개 참고와 작성 범위.

이 패키지는 새 Agent SDK 앱의 범위 확인·최소 생성·실행 검증 절차를 직접 작성한 문서이며 저장소의 MIT License를 따른다. 타사 명령·검증 에이전트 원문은 포함하지 않는다.

- [공식 Agent SDK 개요](https://docs.claude.com/en/api/agent-sdk/overview)에서 지원 환경과 권한·세션·실행 방식을 확인한다.
- [Python 문서](https://docs.claude.com/en/api/agent-sdk/python), [TypeScript 문서](https://docs.claude.com/en/api/agent-sdk/typescript)는 해당 언어를 사용할 때 읽는다.
- [Python 패키지 메타데이터](https://pypi.org/project/claude-agent-sdk/), [TypeScript 패키지 메타데이터](https://www.npmjs.com/package/@anthropic-ai/claude-agent-sdk)에서 선택 버전과 호환 런타임을 확인한다.

현재 버전을 조회하지 못하면 확인된 로컬 버전만 사용하고 최신 버전이라고 표현하지 않는다. 문서 예제의 도구·권한·부가 기능을 요구사항 없이 모두 추가하지 않는다.
