# Codex Windows Shortcut

Windows에서 "이 저장소대로 Codex 세팅해줘"는 Codex를 명시적으로 선택한 최소 세팅 요청이다. [GETTING_STARTED.md](../GETTING_STARTED.md#41-windows-codex-환경-세팅)의 CLI 재사용·공식 설치, 기존 전역 지침 보존과 실행·인증 확인을 따른다.

공식 아이콘 `Codex.lnk` 생성·갱신·독립 검증은 [공통 Windows CLI 바로가기 절차](windows-cli-shortcut.md)에서 **`$client = 'codex'`**를 선택한다. 공식 아이콘은 `~/.codex/assets/icons/codex-official.ico`, 기본 작업 폴더는 실제 바탕화면 아래 `Agent`다. 사용자 지정 폴더를 우선하고 기존 `.bat`는 보존한다. Windows Terminal이 없으면 CMD를 사용한다.

이 주소는 기존 링크와 호환되도록 유지한다. 생성·검증 코드는 공통 문서 한곳에서 관리한다. 단순 "지침 적용"은 규칙을 읽고 따르는 의미다.
