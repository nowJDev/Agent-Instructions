# 설계 진행 체크리스트.

대상은 [자동 회귀 테스트 CI 1단계](superpowers/specs/2026-10-15-regression-ci.md)다.

- [x] 설계와 실행 승인을 확인했다.
- [x] 기존 64개 테스트와 OS별 의존성을 조사했다.
- [x] POSIX 임시 심볼릭 링크 정리 오류를 재현하고 최소 수정했다.
- [x] Windows·Ubuntu workflow와 운영 안내·README 연결을 구현했다.
- [x] 로컬 전체 회귀·Bash 사전 검사·실패 종료 코드·정적 검사·독립 리뷰를 확인했다.
- [x] 실제 GitHub 첫 실행의 Windows fixture 경로 오류를 재현·수정하고 두 OS 재실행 성공을 확인했다. Ubuntu는 60개 통과·4개 의도적 skip, Windows는 64개 전부 통과했다.
- [x] 검증 기록과 한글 커밋을 로컬에 저장했다.
- [x] 사용자 환경에서 패치를 git am으로 적용하고 원격 브랜치와 PR #1을 생성했다. 기존 사용자 main과 미전송 커밋을 보존했다.

CI 1단계 완료 이후 사용자에게 전체 push·병합·정리를 추가 승인받았다.

- [x] PR #1을 병합하고 기존 Chrome DevTools 지침 커밋을 일반 merge로 보존했다. 통합 main의 로컬 전체 64개가 통과했다.
- [x] 미커밋·ignored 파일 부재와 로컬·원격 병합 여부를 확인하고 임시 CI worktree와 작업 브랜치를 정리했다.

필수 병합 규칙 변경·2단계 문서 검사는 이번 통합에 포함하지 않는다.
