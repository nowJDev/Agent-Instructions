# 스킬 출처 기록과 개인 스킬 정리 실행 계획.

**Goal:** 공개 원본 조사 결과를 저장소에 기록하고 요청한 개인 스킬을 두 클라이언트에서 제거한 뒤 검증·커밋·푸시한다.

**Architecture:** 기존 Markdown 출처·카탈로그 구조를 재사용하고 새로운 실행 코드나 의존성은 추가하지 않는다.

**Tech Stack:** Markdown, Git, Python 표준 라이브러리, PowerShell.

**Spec:** [설계](../specs/2026-11-06-skill-provenance.md).

## 공통 경계.

개인 경로·설정·복구 파일을 공개하지 않는다. 과거 기록과 현재 설치·카탈로그 집계를 구분한다. 기능·파서 변경이 없는 문서·명시적 삭제 작업이므로 새 기능 테스트 대신 기존 회귀와 직접 결과 검사를 사용한다.

## 통합 절차.

사용자 요청에 따라 검증한 관련 문서를 한글 커밋으로 묶고 main에 통합·일반 push한 뒤 원격 SHA 일치와 작업 브랜치 정리를 확인한다. 이 문서는 커밋 직전의 실행·검증 기록이며, 후속 통합 성공은 실제 Git 결과와 최종 보고로 확인한다.

검증 증거는 [리뷰 기록](../../reviews/2026-11-06-skill-provenance.md)에 남긴다. 사용자 설치본 삭제는 로컬 작업이며 Git 커밋에는 그 결과의 공개 가능한 기록만 포함한다.
