# 전체 스킬 분야별 안내 설계.

## 승인과 문제.

사용자는 기존 BY-TASK의 엑셀 분야에 3개만 보이는 누락을 지적하고, 구현 전 설계를 요청한 뒤 전체 목록 보완 설계를 승인했다. 기준선은 `f23cadd`다. 기존 구현은 대표 항목과 기존 설명 카탈로그만 대상으로 삼아 현재 시스템·런타임 플러그인을 누락했다. 기존 테스트는 링크의 유효성만 확인해 전수 포함을 보장하지 못했다.

## 목표와 조사 기준.

사용자 전역 직접 패키지, Codex 직접·시스템 패키지, 현재 세션이 제공한 플러그인 패키지 루트와 기존 설명·자체 제작 원본을 대조한다. 현재 세션 노출, 파일 존재, 명시 호출, 과거 비활성, 캐시 내 비노출 부속 항목은 별도 상태다. 공급자 캐시 전체 버전이나 node_modules·references 안의 SKILL을 독립 스킬로 합산하지 않는다. 이름이 같은 서로 다른 구현·배포 설명은 주소와 출처로 구분하고 같은 패키지의 중복 발견은 한 조사 항목으로 기록한다.

## 문서와 데이터.

기존 출처별 상세 설명과 144개 링크를 보존하고, 누락 설명은 소수의 출처별 그룹 README에 추가한다. 자체 제작 원본 26개도 전체 목록에 연결한다. 기존 CATALOG는 등록 항목의 전체 목차, BY-TASK는 전체 등록 항목의 분야별 재배치다. 각 등록 주소는 최소 한 분야에 있어야 하고 여러 분야 공유가 가능하다. 분야 수는 기존 12개로 제한하지 않는다.

빠른 선택 안내 뒤에 분야별 전체 목록을 둔다. 엑셀은 파일 편집·live Excel·분석/시각화·추출/변환을 구분한다. 데이터 분석과 스프레드시트 파일 산출의 차이, live 연결 조건, 명시 호출과 과거 비활성을 보존한다. 분야마다 도구별 상세 설명을 복제하지 않고 같은 정식 주소를 사용한다.

조사 결과는 공개 메타데이터만 담은 `references/skill-inventory-2026-11-12.json`에 기록한다. 출처별 식별자·현재 노출·명시 정책·등록 주소 또는 제외 사유를 보존하며 실제 사용자 절대경로·개인 설정·인증·타사 실행 본문은 포함하지 않는다. 이 파일은 날짜가 있는 조사 증거이며 다른 PC의 설치 상태를 보장하지 않는다. 새 생성기·의존성·실행 스킬 변경은 추가하지 않는다.

## 검증과 배포.

미등록 항목·미분류 주소·원본에 없는 목적지·중복 식별자·설명 없는 제외를 검사한다. 기존 항목 보존·시스템 spreadsheets와 live Excel·Data 분석 도구·동명 구현·명시/비활성 상태를 대상으로 RED→GREEN을 확인한다. 문서 전체 링크와 회귀, 독립 리뷰 후 저장소를 main에 통합하고 기존 승인 범위의 커밋·일반 push와 CI를 확인한다.

검증된 저장소 내용을 전역 밖 백업 후 독립 물리 복제한다. 전역 진입점의 개인 마무리 절, 실제 스킬 설치본·권한·인증을 보존하고 파일 집합·SHA·전역 링크와 원본 접근 차단 회귀로 확인한다. 복제 중 예상하지 못한 파일·reparse·해시 불일치면 중단하고 백업을 유지한다. 실제 원본 삭제·Office 실행·인증·모든 스킬 기능 실행은 이 문서 작업의 완료 주장에 포함하지 않는다.
