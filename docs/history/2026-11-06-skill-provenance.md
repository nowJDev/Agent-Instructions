#### 요청과 기준선.

기준선은 ca45d94다. 사용자는 전수조사 결과를 이 GitHub 저장소에 기록하고 개인 스킬 3개를 삭제한 뒤 커밋·푸시하도록 요청했다. 후속 답변으로 Codex와 Claude 양쪽 설치본 삭제를 지정했다.

<a id="spec--목표와-접근"></a>
#### 목표와 접근.

스킬별 고정 공개 원본·본문 일치·변환·미확인을 references 문서 한곳에 기록하고 기존 출처·이식 안내에서 연결한다. 기존 표만 보강하면 개별 커밋과 변환 경계가 누락되고 원시 감사 자료를 올리면 개인 설치 경로가 공개되므로 허용 필드만 추출한 기록을 선택한다.

개인 스킬 digital-twin-jobs-watch, hexagonal-code-review, us-stock-holding-report의 사용자 전역 설치본만 제거한다. Codex의 전역·별도 설치와 Claude 사용자 설치를 확인하고 실제 존재하는 5개 패키지·12개 파일을 대상으로 한다. 현재 카탈로그의 hexagonal 항목과 개수를 함께 정리하되 과거 변경 이력은 보존한다.

<a id="spec--경계와-실패-처리"></a>
#### 경계와 실패 처리.

타사 원문·개인 설정·보유정보·절대 설치 경로·복구 자료를 커밋하지 않는다. 관련 없는 스킬·MCP·hooks·권한은 변경하지 않는다. 삭제 전 실제 경로·링크 여부를 검증하고 공개 저장소 밖에 해시 검증한 복구 자료를 만든다. 대상 수·경계·해시가 예상과 다르면 삭제를 시작하지 않는다. 열린 세션의 캐시와 디스크 삭제를 구분한다.

### 스킬 출처 기록과 개인 스킬 정리 검증.

<a id="review--범위"></a>
#### 범위.

기준선 ca45d94부터 공개 출처 기록, 현재 카탈로그 정합, 요청한 사용자 스킬 제거를 검토한다. 원시 감사 JSON·개인 경로·복구 파일·타사 실행 원문은 커밋 대상이 아니다.

<a id="review--확인한-증거"></a>
#### 확인한 증거.

- 변경 전 Python 3.12 전체 unittest 72개가 모두 통과했다.
- 세 이름의 사용자 스킬 후보 9개 경로 중 존재하던 5개 패키지·12개 파일을 제거하고 모든 후보 경로 부재를 확인했다.
- 비대상 스킬 본문과 두 클라이언트 설정의 확인 대상 136개 파일 해시가 유지됐다. 복구 파일은 저장소 밖에 있다.
- 삭제 이후 감사 집계는 전역 103개와 별도·내장·플러그인 30개다. 공개 본문 일치 103개·차이 9개·실행 원본 미확인 3개·공식 배포 확인 18개를 구분한다.

<a id="review--변경-후-검증"></a>
#### 변경 후 검증.

- [x] 변경 후 Python 3.12 전체 unittest 72개가 실패·오류·skip 없이 통과했다.
- [x] 카탈로그 99개·OFF 22개·개인 5개, 전역 출처 103행·고정 원본 링크 112개, 변경 문서 링크 240개와 UTF-8·BOM·개인정보 경계를 확인했다. git diff --check도 통과했다.
- [x] 독립 전체 리뷰에서 확정 결함을 발견하지 못했다. 감사 공개 필드 133행·고정 링크·집계가 일치했고 캐시로 독립 대조 가능한 본문 81개도 일치했다.

<a id="review--git-반영-경계"></a>
#### Git 반영 경계.

기록 작성 시점은 커밋 직전이다. 사용자가 한글 커밋·main 통합·일반 push를 요청했으며, 후속 반영 결과는 실제 Git 로그·원격 main SHA와 최종 보고로 확인한다. 복구 자료와 원시 감사 파일은 스테이징하지 않는다.

실제 스킬 호출·MCP 인증과 새 세션 발견은 이번 파일 삭제·출처 문서 검증에 포함하지 않는다. Superpowers를 제외한 모든 보조 리소스의 원본 내용 전수 비교도 수행하지 않았다.

<a id="review--설치-버전-누락-보완"></a>
#### 설치 버전 누락 보완.

사용자 지적에 따라 de0d443 이후 제작자 계보 표와 개별 설치본 133개 표에 버전·빌드와 정규화 본문 식별자를 추가했다. 설치 기록, 플러그인 manifest, 자체 frontmatter version 7개와 metadata.version 2개를 확인했다. 원본 플러그인 버전을 이식본 자체 버전과 구분하며 버전 미표기·미확인을 명시했다. 비교 원본 Git 커밋을 설치 버전명으로 바꾸지 않는다.

- [x] 현재 설치 파일에서 133개 정규화 본문 SHA-256이 일치하고 기존 원본 링크 112개·이름·분류·판정이 보존됨을 확인했다.
- [x] 상단 12계열의 버전 요약, 개별 표 103행·30행과 버전 선언·공개정보·문서 링크 125개를 검사했다.
- [x] 보완 후 Python 3.12 전체 회귀 72개가 실패·오류·skip 없이 통과했다. 독립 리뷰는 현재 설치 manifest와 자체 버전 선언을 재확인했다.

버전 필드와 본문 식별자는 조사 시점의 파일 상태이며 실제 스킬·라이브러리 실행 버전이나 향후 업데이트를 보장하지 않는다. 스킬 설치본 자체는 변경하지 않았다.
