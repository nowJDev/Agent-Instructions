<a id="spec--superpowers-702-전역-업데이트-설계"></a>
### Superpowers 7.0.2 전역 업데이트 설계.

<a id="spec--승인과-목표"></a>
#### 승인과 목표.

사용자는 대화에서 제시한 상세 설계를 승인하고 글로벌 전체와 바탕화면 Agent-Instructions 저장소의 반영을 요청했다. Claude Code와 Codex의 Superpowers를 5.1.0에서 7.0.2로 통일한다. 원본은 obra/superpowers의 v7.0.2, 커밋 `22f0b463e7a5e579904dd6211a520321035526f7`이다.

<a id="spec--배치와-경계"></a>
#### 배치와 경계.

Claude는 제작자 superpowers-marketplace를 등록하고 기존 claude-plugins-official 출처를 비활성화한 뒤 제작자 플러그인만 활성화한다. Codex는 기존 `~/.agents/skills/<name>` 패키지 구조를 유지한다. 14개 패키지를 통째로 교체하고 diagnosing-superpowers를 추가한다. 타사 스킬 원문은 이 공개 저장소에 복사하지 않는다.

기존 사용자 제작 스킬, 전역 행동 지침, 인증 정보, 다른 플러그인과 권한은 보존한다. 수정 범위는 Superpowers 카탈로그, 관련 인덱스·개수·설치 안내와 이번 작업 문서다. 글로벌 문서 복사본에는 동일한 관련 변경만 적용한다. 과거 백업과 이전 작업 기록은 현행 설치본으로 취급하지 않는다.

<a id="spec--실패와-복구"></a>
#### 실패와 복구.

원본·현재 파일·설정의 로컬 백업과 해시를 먼저 확보한다. 배포 채널의 실제 버전이 승인 버전과 다르면 설치 전에 확인한다. 패키지 교체 중 실패하면 변경한 패키지만 이전 백업으로 복원하고 새 Claude 출처를 비활성화한 뒤 기존 출처를 다시 활성화한다. 문서·설치 기록도 함께 복구한다. 백업은 검색 경로 밖에 보관한다.

<a id="spec--검증과-완료-기준"></a>
#### 검증과 완료 기준.

원본 15개 스킬의 파일 목록·해시, 상대경로와 스크립트 정상·실패 흐름을 확인한다. 비대상 파일·설정의 보존, Claude 단일 활성 출처, Codex 중복 부재, 저장소 전체 회귀와 새 세션의 스킬 발견·읽기를 검증한다. 새 세션 또는 계정 인증 때문에 확인할 수 없는 항목은 검증 기록에 명시한다. 실제 외부 게시와 로그 업로드는 수행하지 않는다.

검증과 전체 리뷰 후 한글 커밋을 만들고 승인된 로컬 main에 통합한다. 원격 push는 요청 범위에 포함하지 않는다. 병합 후 에이전트가 만든 작업 브랜치와 worktree만 정리하고 복구용 백업은 보존한다.

### Superpowers 7.0.2 업데이트 실행 계획.

목표는 [승인 설계](#spec)의 전역 설치와 문서 반영이다. Python 표준 라이브러리, Git, 설치된 Claude·Codex CLI를 사용한다. 실행은 현재 세션에서 수행하며 문서 작성·독립 리뷰를 위임한다.

- [x] 현재 설치·설정·문서 원본과 저장소의 깨끗한 기준선 `0acf0a0`을 확인한다.
- [x] 별도 worktree와 작업 브랜치를 준비한다.
- [x] 기존 스킬·설정·글로벌 문서를 로컬 백업하고 비대상 파일 해시를 기록한다.
- [x] v7.0.2 고정 커밋의 전체 원본을 준비하고 스킬 15개·80파일의 Git blob 해시를 확인한다.
- [x] 저장소 기존 회귀 테스트를 실행하고 기준선을 확인한다.
- [x] Claude 제작자 marketplace를 준비하고 Superpowers 출처를 전환한다.
- [x] Codex 기존 14개 패키지를 교체하고 diagnosing-superpowers를 추가한다.
- [x] 카탈로그 15개와 관련 인덱스·개수·설치 안내를 갱신한다.
- [x] 실제 설치 기록과 글로벌 문서 복사본을 갱신한다.
- [x] 원본 해시·비대상 보존·중복·스크립트와 새 세션 검증을 실행하고 Claude 인증 제한을 기록한다.
- [x] 전체 회귀·독립 리뷰·문서 정합 검사를 수행하고 결과를 기록한다.
- [x] 한글 커밋·로컬 main 통합 후 임시 작업 공간을 정리한다.

<a id="plan--검증-명령"></a>
#### 검증 명령.

저장소 회귀는 Git for Windows bin과 usr/bin을 PATH에 둔 Python으로 `python -X utf8 -B -m unittest discover -s tests -v`를 실행한다. 완료 문서는 `Owned-Skills/design-driven-delivery/scripts/validate_workflow.py`에 이번 설계·계획·리뷰 파일을 지정한다. 글로벌 설치 검증은 로컬 원본·백업을 비교하며 개인 설정과 로그는 공개 커밋에서 제외한다.

<a id="plan--검토-초점"></a>
#### 검토 초점.

다른 플러그인·사용자 지침 보존, 검색 경로 안에 남는 구버전, 최신으로 잘못 표기한 배포 채널, 이동된 참조 파일, 부분 교체 시 복구를 확인한다. 설치 성공·새 세션 검증·원격 배포 결과를 구분한다.

Claude 새 세션의 15개 스킬 발견까지 확인했다. 실제 모델 호출은 로그인 필요 오류로 실행되지 않았으며 사용자의 `/login` 이후 추가 확인이 필요하다. 이 항목은 설치 적용과 검증 시도 완료로 기록하며 모델 호출 통과로 해석하지 않는다.

<a id="review--superpowers-v702-업데이트-검증"></a>
### Superpowers v7.0.2 업데이트 검증.

<a id="review--범위와-기준"></a>
#### 범위와 기준.

기준선은 `0acf0a0`이다. [승인 설계](#spec)와 [실행 계획](#plan)에 따라 글로벌 Superpowers와 이 저장소의 카탈로그·설치 안내를 갱신한다. 개인 설정·인증·로컬 로그·타사 스킬 원문은 공개 커밋에서 제외한다.

<a id="review--확인한-설치-상태"></a>
#### 확인한 설치 상태.

- Claude 등록 버전과 매니페스트는 7.0.2이며 원본 SHA는 `22f0b463e7a5e579904dd6211a520321035526f7`이다. 제작자 출처만 활성화했고 기존 공식 출처는 비활성 상태로 복구용 보존했다.
- Codex 15개 패키지·80개 파일의 목록과 바이트 해시는 고정 원본과 일치했다. Claude 80개 파일도 CRLF를 정규화하면 동일했다. Git for Windows의 자동 줄바꿈 변환이며 실제 스크립트 실행은 정상이다. 관리되는 Claude 캐시를 임의 수정하지 않았다.
- 기존 비대상 파일 555개의 SHA256이 동일했다. 여기에는 사용자 제작 스킬, 전역 행동 지침과 Codex 설정이 포함된다. Claude 설정은 승인된 두 enabledPlugins 항목과 제작자 marketplace 등록만 변경했다.
- Claude CLI의 설정 직렬화가 기존 알림 훅 두 항목의 `_managed_by` 메타데이터를 생략해 원본을 복원했다. 훅 명령·순서·나머지 설정은 보존했다.

<a id="review--실행-검증"></a>
#### 실행 검증.

| 검사 | 관찰 결과 |
|---|---|
| 저장소 변경 전 전체 회귀. | Python unittest 72개 통과, 실패·오류·skip 0개. |
| 양쪽 설치본 Bash·Node 구문. | Bash 18개, Node 6개 검사 통과. |
| 양쪽 설치본 보조 도구. | 설치본별 8개, 총 16개 시나리오 통과. |
| Codex 새 앱 서버 skills/list. | 두 작업 경로에서 각 15개 활성, 동명 중복과 해당 스킬 오류 없음. |
| Codex 읽기 전용 새 세션. | diagnosing-superpowers와 using-superpowers의 실제 설치 파일·버전 기록을 읽고 7.0.2와 transcript 근거 요구를 확인했다. |
| Claude 새 세션 초기화. | 제작자 출처의 스킬 15개를 발견했다. |
| Claude 실제 모델 호출. | 미검증. `Not logged in · Please run /login`으로 모델 응답 전 종료했다. |

보조 도구 검증은 임시 Git 저장소에서 저장소 밖 실행의 exit 2·부작용 부재, 첫 커밋이 없는 저장소에서 task-start 거부, `-C` 지정, 정상 작업 공간·plan-path, task-start, 무출력 성공 기록, 실패 명령의 원장 불변, 잘못된 BASE와 없는 `-C` 경로를 검사했다. 실제 사용자 프로젝트·세션 기록은 시험 자료로 사용하지 않았다.

<a id="review--남은-확인과-복구"></a>
#### 남은 확인과 복구.

사용자가 Claude에서 `/login`을 마친 뒤 새 세션에서 신규 진단 스킬의 실제 호출을 확인해야 한다. 인증 정보 변경과 로그인 자동화는 수행하지 않았다. 설치 완료·스킬 발견과 실제 모델 호출 성공을 구분한다. 모든 글로벌 변경은 검색 경로 밖의 로컬 백업과 설치 기록에서 이전 값·파일 해시를 확인해 복구할 수 있다.

<a id="review--문서회귀독립-리뷰"></a>
#### 문서·회귀·독립 리뷰.

변경 후 저장소 전체 회귀 72개가 26.016초에 통과했으며 실패·오류·skip은 0개다. 독립 리뷰에서 Codex 15개·80파일의 원본 해시, 카탈로그 15개, 공개 문서 내부 링크·앵커, 원본 참조 파일명, UTF-8 BOM 부재, 개인 경로 부재와 diff-check를 다시 확인했다. 차단·중요 결함은 발견되지 않았고 첫 커밋이 없는 저장소의 실패 조건 설명을 구체화했다.

관련 문서 25개를 글로벌 문서 복사본에 반영했다. 그중 PORTABILITY·스킬 인덱스·현재 상태의 기존 차이는 보존해 병합했고 비대상 문서 223개는 바이트 동일함을 확인했다. 글로벌 알림 훅과 비대상 555개 파일도 다시 확인했다. Windows SessionStart 래퍼는 exit 0으로 최신 진입 스킬 본문을 정확히 출력하고 중복 컨텍스트 필드가 없었다.

구현 커밋 `a7d9b3c`을 로컬 main에 fast-forward 통합했다. 원격 조회 당시 main과 origin/main의 차이는 없었다. 병합된 main의 전체 회귀 72개도 26.227초에 모두 통과했으며 실패·오류·skip은 0개다. worktree의 미커밋·미추적·ignored 파일 부재와 main 포함 관계를 확인한 뒤 이번 작업의 worktree와 브랜치를 정리했다. 로컬 복구 백업과 설치 기록은 보존했다. 원격 push와 외부 이슈·로그 게시를 수행하지 않았다.
