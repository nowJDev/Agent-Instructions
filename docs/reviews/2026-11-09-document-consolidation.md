# 문서 통합 검증과 배포.

## 범위.

기준은 a559c66이다. [승인 설계](../superpowers/specs/2026-11-09-document-consolidation-design.md)와 [실행 계획](../superpowers/plans/2026-11-09-document-consolidation.md)에 따라 카탈로그·작업 이력을 통합하고 기존 글로벌 복사본과 GitHub에 반영한다. 사용자가 실행·글로벌·커밋·push를 승인했다.

## 구현과 대상 검증.

- 기존 Windows Python3.12 전체72개가 통과했다.
- 문서 회귀5개를 추가하고 기존 배치에서 카탈로그·이력 부재2개 RED를 확인했다. 통합 후5개가 통과했다.
- HF 예제의 파일 경로 부재로 기존4개 테스트가 실패하는 것을 확인하고 해당 항목만 추출하도록 변경해4개가 통과했다.
- 카탈로그121개·보관 원문37개의 제목 매핑과 코드 블록 불변을 비교했다. 개인 추가 자료는 공개 통합 대상으로 사용하지 않았다.
- 공식 [Codex MCP 설정](https://learn.chatgpt.com/docs/extend/mcp)의 초 단위 startup_timeout_sec와 [Firecrawl 모니터](https://docs.firecrawl.dev/features/monitoring)의 최소5분을 확인해 불일치를 수정했다.

## 전체 검증과 리뷰.

Windows Python3.12 전체80개가 실패·skip 없이 통과했다. 코드 예제·원문을 독립 대조했고 Owned-Skills62개와 출처 JSON은 기준선과 같았다. 추적154개와 내부 링크·앵커·UTF-8·펜스 검사를 확인했다.

독립 리뷰에서 설치 대상 선택 정책 누락, 인라인 코드 앵커 오인, daily-work-report의 고유 검증 증거 누락을 확인했다. 각각 실패 반례3개를 먼저 확인한 뒤 정책을 설치 절차 한곳에 복원하고 코드 범위를 제외하며 원래 증거를 관련 보관 기록에 추가했다. 대상8개와 전체80개가 다시 통과했다.

GitHub GFM API로 공개 문서10개를 렌더링하고 Chrome에서 목차121개 링크, 기본·개인·Firecrawl3개 그룹, Vercel 내부 개발 항목과 과거 리뷰 절을 확인했다. 로컬 미리보기에는 GitHub 웹의 자동 제목 ID에 대응하는 탐색용 ID를 부여했으며 원본 Markdown은 변경하지 않았다. Mermaid의 GitHub 웹 실행과 원격 CI는 이 시점의 로컬 표시 검사에 포함하지 않았다.

## 글로벌 적용과 GitHub.

기존 활성 설정 홈의 소유 문서와 개인 추가 파일을 구분하여 비공개 백업·보존 병합한다. 설정·인증·실행 스킬은 보호하고 새 세션 로드와 원격 CI는 실제 결과를 기록한다. 아직 수행하지 않은 배포·push를 성공으로 표시하지 않는다.

## 남은 검증 경계.

문서의 단순 구조 검사가 의미의 정확성이나 실제 서비스 동작을 보장하지 않는다. 이전 Claude 모델 호출·외부 로그인·GPU 실행의 미검증은 그대로 보존한다. 이전 main 개별 문서 URL은 새 주소로 바뀌며 원문은 고정 커밋으로 조회한다.
