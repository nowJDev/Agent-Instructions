# 분야별 안내와 전역 복제 검증.

## 범위와 기준.

기준선은 `26d70e7`이며 [설계](../superpowers/specs/2026-11-12-task-navigation-design.md)·[계획](../superpowers/plans/2026-11-12-task-navigation.md)을 따른다. 분야별 선택 안내·한영 README·기존 카탈로그 진입점·문서 테스트와 이번 증거 문서를 변경한다. 실행 스킬·고정 명세·기존 history·인증·권한은 보존한다.

## 확인한 증거.

- 로컬 Windows·Python 3.11.9에서 기준선 전체 103개 테스트가 실패·오류·skip 없이 통과했다. 기존 CI는 Python 3.12를 유지한다.
- 신규 안내와 네 진입점이 없는 상태에서 신규 테스트 3개의 예상 RED를 확인했다. 구현 후 문서 대상 11개가 통과했다.
- 12개 분야의 대표 목적지·기존 설명 재사용·세 분야의 OfficeCLI 공유·명시 호출·과거 비활성 안내와 기존 144개 상세 링크·26그룹을 검사했다.
- 엑셀 수식 편집·SVG PPT·한글 문서·버그 원인 조사에서 해당 상세 절까지의 경로를 수동 대조했다.
- 전역 차이 61개 중 60개는 과거 공개 Git 본문과 일치했다. 나머지 카탈로그의 개인 보존 링크와 extra 개인 문서는 전역 밖 백업 대상으로 확인했다. 개인 내용은 공개하지 않는다.
- 설치 스킬의 정적 의존성을 별도 조사했다. 사용자 스킬 텍스트 3,782개·시스템 포함 스킬 텍스트 58개에서 원본 작업 폴더 참조와 reparse point를 발견하지 않았다. 실제 실행·인증 성공을 뜻하지 않는다.
- 구현 후 저장소 전체 106개 회귀가 실패·오류·skip 없이 통과했다. 문서 링크·앵커와 기존 카탈로그 구조를 포함한다.
- 전역 기존 165개 파일과 진입점을 복제본 밖의 비공개 백업에 복사하고 상대경로·SHA256을 대조했다. extra 8개는 백업 해시를 확인한 뒤 활성 복제본에서 개별 제거했다. 전역 진입점은 최신 템플릿에 개인 마무리 절을 보존했다.
- 새 문서 집합 177개와 전역의 파일 집합·SHA256이 일치했고 전역 Markdown 148개의 내부 링크 오류와 reparse point는 0개였다. 최종 기록 변경 후 동일성을 다시 확인한다.
- 전역에서 원본 저장소·임시 worktree의 파일 열기·디렉터리 탐색·작업 경로 변경을 거부하는 Python 감사 훅을 적용했다. 차단 자체의 실패 사례를 확인한 뒤 전체 106개 회귀가 실패·오류·skip 없이 통과했다. 원본 폴더를 실제 삭제하지 않고 독립 실행을 확인했다.
- 신규 파일을 포함한 12개 변경 파일의 독립 리뷰에서 확정 결함을 발견하지 못했다. 리뷰어가 문서 11개 검사와 diff 검사를 재실행했으며 전역 복제의 증거는 위 별도 검증으로 구분했다.

## 진행 상태.

자동·수동 검증과 독립 리뷰를 마쳤다. 커밋·main 통합·원격 SHA·CI와 소유 임시 작업 공간 정리는 배포 후 기록한다. 새 AI 세션에서 자동 선택이나 Office 실행 품질 개선을 검증한 것으로 보고하지 않는다.
