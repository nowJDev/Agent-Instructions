# 전체 스킬 누락 보완 검증.

## 범위와 원인.

기준선은 `f23cadd`이며 [설계](../superpowers/specs/2026-11-12-skill-coverage-design.md)·[계획](../superpowers/plans/2026-11-12-skill-coverage.md)을 따른다. 이전 안내는 대표 항목만 고르고 기존 설명 카탈로그로 목적지를 제한해 시스템·현재 플러그인과 분야별 전수 포함을 놓쳤다. 기존 106개 회귀 성공은 완전성의 증거가 아니었다.

## 조사와 등록 증거.

- 직접 패키지는 사용자 130개·Codex 사용자 1개·시스템 5개, 합계 136개다. 기존 상세 설명 94개·자체 제작 원본 26개·신규 보완 16개로 대조했다.
- 현재 세션이 제공한 17개 플러그인의 선택된 버전에서 직접 패키지 108개를 확인했다. 세션 노출 59개와 금융 라우터 전문 가이드 44개·Data 부속 5개의 직접 비노출을 분리했다.
- 유효 조사 패키지는 244개이고 조사 세션 노출은 181개다. 명시 정책 63개와 세션 비노출을 별도로 기록했다. 루트 SKILL이 없는 `firecrawl-cli`·`skill-gen` 후보는 제외 사유를 남겼다. 캐시의 모든 버전·의존성 내부 파일은 합산하지 않았다.
- 기존 144개 설명 주소와 자체 제작 원본 26개를 보존하고 124개 보완 주소를 추가해 등록 주소는 294개다. 등록 주소와 유효 설치·노출 수는 분모가 다르다.
- 전체 등록 주소를 16개 분야에 배치했다. 엑셀 32개 관련 항목은 파일 편집·live Excel·분석·추출·금융 모델을 구분하며 금융 전문 가이드를 일반 편집 도구로 세지 않는다.
- 공개 [조사 증거](../../references/skill-inventory-2026-11-12.json)는 출처·버전·정책·노출·등록/제외·분야를 담고 개인 절대경로·인증·개인 참조·원문 실행 본문은 포함하지 않는다. 로컬 `code-review`·`handover`의 개인 추가 참조는 공개 원본으로 복제하지 않았다.

## 자동·수동 검증.

Windows·Python 3.11.9에서 기준선 전체 106개 회귀가 실패·오류·skip 없이 통과했다. 신규 완전성 검사 두 개가 기존 분야 누락과 조사 증거 부재로 실패하는 RED를 확인했다. 보완 후 문서 대상 13개가 통과했다. 28개 상세 그룹·294개 등록 주소·모든 분야 연결·244개 유효 조사와 2개 제외·17개 플러그인·명시 정책·미노출 설명·내부 링크를 검사한다.

구현 후 전체 108개 회귀가 실패·오류·skip 없이 통과했다. 독립 리뷰는 원본 조사 244개와 공개 레코드·기존 144개 주소·전체 분야 포함·정책·직접 비노출을 대조했다. 금융 상위 라우터 두 개를 하위 전문 스킬로 분류한 metadata 불일치를 발견해 회귀로 RED를 재현하고 `plugin-router`로 고친 뒤 문서 13개와 전체 108개 회귀 GREEN을 확인했다. 수정 후 남은 확정 결함은 발견하지 못했다. 기존 자체 제작 실행본·고정 명세·MCP·상세 원본·history는 변경하지 않았다.

전역 기존 문서와 진입점을 복제본 밖의 비공개 백업에 보존하고 파일 집합·SHA를 확인했다. 전역 진입점의 개인 지침과 바이트를 보존하며 183개 파일을 독립 물리 복제했다. 파일 집합·각 SHA256이 일치하고 153개 Markdown 내부 링크 오류와 reparse point는 0개였다. 원본 저장소·작업 공간의 파일 열기·디렉터리 조회·작업 경로 변경을 거부하는 감사 훅을 적용하고, 차단 자체의 실패 사례 확인 후 전역 전체 108개 회귀가 실패·오류·skip 없이 통과했다.

현재 커밋·통합·배포 확인을 진행한다. 원본 실제 삭제와 모든 스킬의 실제 실행·인증은 이 문서 작업의 검증 대상이 아니다. 최종 기록 변경 후 전역 파일 집합·SHA·링크를 다시 대조한다.
